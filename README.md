# STAR.CORE-inspired auth terminal (unofficial demo)

A responsive, static frontend study of an ARG-inspired authentication experience. This is **not the official staryuki.com website**. No personal credentials should be entered.

## Try it

- Clearance key `HATSUNE` (or `SKIP`) to access the simulated terminal.
- Enter `login` or `register` in the terminal (or use the shortcut buttons).
- Built-in demonstration account: `demo@starcore.local` / `demo12345`.
- Registration creates a **temporary in-memory** identity. It is removed after reloading the page. No backend, server request, analytics, or account storage.

## Deploy

This is one `index.html` file with inline CSS and JS. Publish it from the repository root via GitHub Pages (Settings -> Pages -> Deploy from a branch -> main -> / (root)). No npm build or environment variables are needed. All links are relative and work in project subdirectories.
